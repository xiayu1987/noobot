# Three.js sample model attributions

The following files are copied from the Three.js `r180` examples model
catalog: `RobotExpressive.glb`, `Soldier.glb`, `Flamingo.glb`, `Horse.glb`,
and `Parrot.glb`.

Source repository: <https://github.com/mrdoob/three.js/tree/r180/examples/models/gltf>

Three.js is distributed under the MIT license. Individual example models may
have additional creator or source-model terms. This catalog keeps the model
filenames and source revision stable so attribution can be audited; consult
the upstream repository and its model-specific notices before external
redistribution or commercial use.
