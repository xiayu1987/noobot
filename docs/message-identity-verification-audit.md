## V07：负向夹具、草稿与错误边界

- `plugin/noobot-plugin-harness/__tests__/helpers/context-message-input-contract.test.js` 保留调用者显式的非法身份、回合归属和损坏 modelContext，不经工厂修正；缺省测试上下文可以由合法工厂创建，已声明的非法值必须拒绝。`required-model-context` 测试覆盖缺失、版本不支持和损坏 messages/messageBlocks/lane，拒绝后原输入不变。
- agent `__tests__/helpers/canonical-session-messages.js` 统一合法持久化消息夹具；包装器委托共享实现，调用方显式字段最后覆盖，允许直接构造负向样本。`TEST_MESSAGE_TS` 是规范 ISO 字符串；service 自有测试 helper 不跨包依赖 agent 测试内部实现。
- `context-protocol/src/message/session-projection.js` 投影的是会话消息草稿，不要求草稿已有持久化 ts、messageOrigin 等落盘事实；附件缺省由 session-protocol 的 `readSessionMessageDraftAttachments` 明确定义，显式非法容器拒绝。持久化入口仍执行实体完整校验，不能用草稿投影代替落盘校验。
- 本轮发现并修复：会话记录入口原会裁剪 messageUid、把 role 转小写。现在 messageUid 双向投影复用公开 `session-protocol/message-identity:assertMessageIdentity`，会话角色按规范值精确匹配；删除会话投影的默认空 record。新增空白/空值/非字符串身份、大写/别名/空白角色拒绝与输入不变回归，并更新旧测试的协议错误断言。
- Context → Session 的角色读取仍使用 codec 的公开适配规则：Context 支持 provider/LangChain 的 role/type 形状，会话记录则只接受规范角色。两种输入契约不同，不在会话记录入口复制 Context 别名规则。
- `globalErrorBoundary` 单元测试覆盖 Vue 渲染错误与 unhandledrejection。隔离浏览器报告 `workspace/admin/runtime/ops_workdir/v-audit-browser.json` 记录真实 Vue 渲染失败和原生 unhandledrejection 产生两条用户通知（2/2）；这是隔离 localhost 证据，不是完整应用生产 E2E。复现探针保留为证据；探针服务当前是否仍运行尚未核实，不据此声明已完成进程清理。

结论：V07 列明的测试旁路、共享夹具和错误展示核实完成。V05 历史八条原始样本未取得，不能凭合法夹具或本轮全仓通过销账。
