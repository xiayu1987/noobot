GPT-6.1 Terra 的工具调用使用 Responses API，图片输入和缓存字段沿用 GPT-6 系列声明。两款 Claude 使用现有原生 Messages 适配器和 adaptive thinking；不声明 `none`，因为 Sonnet 5.5 的最低思考模式需要额外的 `between_tools` 请求语义。

Kimi 使用现有 OpenAI 兼容接口及缓存协议。MiniMax 使用 OpenAI 兼容接口，密钥和地址变量分别为 `MINIMAX_API_KEY`、`MINIMAX_API_ADDRESS`，官方地址为 `https://api.minimax.io/v1`。MiniMax 声明图片和视频输入；缓存为服务端自动缓存，不向请求添加未经确认的显式缓存字段。其推理不能关闭，因此不提供 `none`。模型库中的参数字段不是运行时按型号猜测的兼容分支。

Gemini 在 noobot 中通过 OpenAI 兼容接口调用，全部 Gemini 模板的 `reasoning_effort_parameter` 修正为 `reasoning_effort`；原生接口的 `thinking_level` 不能直接作为顶层 OpenAI 请求参数。Gemini 3.1 Pro Preview 的项目默认思考档位同步为官方的 high。以上变更同步到已有的配置示例条目，不重写用户运行配置。[Google 思考档位](https://ai.google.dev/gemini-api/docs/thinking)、[OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)。

Qwen3.8 Omni Flash 使用 `reasoning_effort`，与 Qwen Max/Flash 模板使用的 `enable_thinking` 开关不同；直接提供 none / low / medium / xhigh 四个实际档位，不重复显示映射到同一档位的兼容别名。该模型声明图片、音频和视频理解以及文本输出，使用隐式缓存，不发送旧的显式缓存标记。

## 三代清理规则

沿用此前目录更新规则：按同厂商、同产品线已发布的连续版本计算，至少三次后续升级才移出内置库；不同档位和同版本快照不重复计代。已宣布未来下架的模型，不视为当前已下架。

- 移出 `gpt_5_5` / `gpt-5.5`：`5.5 → 5.6 → 6 → 6.1`，落后三次版本升级。这是本项目的目录保留策略，不是 OpenAI 官方下架声明。[官方模型列表](https://developers.openai.com/api/docs/models)、[退役公告](https://developers.openai.com/api/docs/deprecations)。
- GPT-5.6 各档位、GPT-6 Sol/Luna/Astra 保留。不同档位不互相替代；不把 GPT-6.1 Terra 的发布算作 GPT-6.1 Sol 之后的新一代。
- Claude Opus 5、Sonnet 5、Haiku 4.5 保留：同产品线没有三次后续版本升级，且官方仍列为 Active。[生命周期公告](https://platform.claude.com/docs/en/about-claude/model-deprecations)。
- Gemini 3.1 Pro Preview 保留：Pro 产品线不能拿 Flash 版本数字衡量老化程度，官方尚未宣布其关闭日期。Gemini 3.7 Flash 是仍可访问、自动转发到 3.8 Flash 的别名，保留已有引用。[Google 模型列表](https://ai.google.dev/gemini-api/docs/models)、[生命周期公告](https://ai.google.dev/gemini-api/docs/deprecations)。
- Qwen 3.6 Flash、3.7 Max/Plus 保留：不跨档位计代，尚未满足三次后续升级。[阿里云模型列表](https://www.alibabacloud.com/help/en/model-studio/models)。
- DeepSeek Flash / V4 Pro、Grok 4.7 / 4.6、GLM-5.3 / 5.2、Kimi K3 保留。[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)、[xAI](https://docs.x.ai/developers/models)、[Z.AI](https://docs.z.ai/guides/llm/glm-5)、[Kimi](https://platform.kimi.ai/docs/models)。这些厂商已有的最新主流条目不重复新增。

## 生效范围

内置模型库由服务进程导入，重新启动或重新部署服务后，配置页面“从模型库添加”会读取新列表。已有配置、默认模型、密钥、用户自定义地址和历史会话保持原样；已有 GPT-5.5 配置仍可访问，内置库不再推荐新增。没有进行付费模型调用，也不以厂商发布状态推断用户第三方渠道的可用性。
